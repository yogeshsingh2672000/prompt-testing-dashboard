# Promitly v0.1.0

Promitly `v0.1.0` is the first public release of a local-first prompt QA platform built for developers who want to test prompts privately without relying on a hosted prompt testing product.

## Highlights

- local-first workspace for prompt authoring, datasets, results, and history
- multi-provider evaluation support across AWS Bedrock, OpenAI, Anthropic, and Google Gemini
- structured output validation, rubric scoring, analytics, prompt comparison, reviews, schedules, and exportable reports
- session-only runtime credentials for users who do not want to reuse maintainer keys
- contributor-ready repo assets including CI, issue templates, PR template, changelog, and launch positioning

## Why This Release Matters

This release turns Promitly into more than a dashboard. It is now a credible open-source starting point for teams that want private prompt QA, local evaluation, and provider flexibility without exposing prompt logic to a third-party evaluator.

## Current Limitations

- runs, schedules, datasets, and settings are stored locally in IndexedDB
- scheduled runs depend on the app being open
- no shared cloud workspace or auth layer yet
- semantic scoring still relies on an additional model evaluation pass

## What Is Next

- CLI and CI-first execution for prompt regression gates
- richer schema-aware validation
- flaky-case analysis and rerun tooling
- stronger provider diagnostics and setup guidance
